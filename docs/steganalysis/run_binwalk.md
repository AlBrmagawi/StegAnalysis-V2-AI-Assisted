# Binwalk

Deep optionally runs a read-only signature scan. Automatic extraction is disabled. Missing tools are skipped, and version/arguments/exit/output/deadline records are retained.

See [current analyzer contracts](../analyzers.md), [workflow](../usage.md) and [the legacy audit](../provenance-and-licensing.md). Original creators: Mohamed Abdelgalil (AlBrmagawi) and Spooky. The pre-rebuild implementation remains in Git history.
