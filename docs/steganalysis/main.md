# Compatibility entry point

`python script.py -f <file>` delegates to the shared CLI and bounded engine. There is no startup installation, sudo invocation, global output directory, or undefined WAV call. Use `steganalysis analyze --help` for profiles, JSON and output options.

See [current analyzer contracts](../analyzers.md), [workflow](../usage.md) and [the legacy audit](../provenance-and-licensing.md). Original creators: Mohamed Abdelgalil (AlBrmagawi) and Spooky. The pre-rebuild implementation remains in Git history.
