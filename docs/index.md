# StegAnalysis V2

Local evidence. Traceable findings. Defensible conclusions.

Create a case → add evidence → run Quick, Standard or Deep → inspect findings and supporting artifacts → record analyst reasoning → export a reproducible report.

Original creators: **Mohamed Abdelgalil (AlBrmagawi)** and **Spooky**. The original repository has no declared project license; see the provenance and licensing page before redistribution.

![Real generated-fixture investigation](screenshots/investigation-desktop.png)

The image shows an actual run of benign generated fixtures. No invented case results are seeded into the dashboard. Core PDF, image, integer PCM WAV and text analysis works without a model, API key, GPU or optional tool.

Start with [installation](installation.md) and [the workflow](usage.md). Read [analysis methods](analyzers.md) before interpreting indicators as conclusions. [Security](security.md) explains the local single-user boundary; [assistant privacy](assistant.md) explains exact hosted consent; [experimental ML](ml.md) reports the baseline's poor synthetic performance without a production claim.

The workbench preserves originals, hashes at ingestion, records every analyzer outcome and links derived artifacts to their generating runs. Findings, heuristic suspicion, verified demo recovery, model scores and analyst conclusions stay separate.
